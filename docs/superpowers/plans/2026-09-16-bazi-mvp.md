# 八字分析 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deployable, privacy-first Chinese-standard-time lunar-date BaZi report MVP powered by Gemini.

**Architecture:** A Next.js App Router application has two UI routes and two server routes. Pure `lib/bazi` functions convert lunar input and deterministically derive the chart; `lib/gemini` owns all model configuration, prompt, invocation, and response parsing; Supabase receives only minimal feedback through the server.

**Tech Stack:** Next.js App Router, TypeScript, Tailwind CSS, Vitest, Zod, lunar-typescript, @google/genai, @supabase/supabase-js.

**Spec:** `docs/superpowers/specs/2026-09-16-bazi-mvp-design.md`

## Global Constraints

- Accept only lunar date plus 24-hour time; all calculations use `Asia/Shanghai`.
- Treat 13:00 through 14:59 as 未时.
- Do not store or log raw birth input, chart data, or generated report.
- Default Gemini model is `gemini-3.1-pro-preview` with `thinkingLevel: HIGH`.
- Model sections are dynamic; no fixed report-module structure in React.
- Supabase feedback contains only rating, deep-analysis opt-in, and timestamp.

const BRANCHES = ['子', '丑', '寅', '卯', '辰', '巳', '午', '未', '申', '酉', '戌', '亥'];
export function hourBranch(hour: number) {
  return BRANCHES[Math.floor(((hour + 1) % 24) / 2)];
}

export const ReportSchema = z.object({
  title: z.string().min(1), summary: z.string().min(1),
  sections: z.array(z.object({ heading: z.string().min(1), body: z.string().min(1), bullets: z.array(z.string()) })).min(1),

});
export const parseReport = (value: unknown) => ReportSchema.parse(value);
